# Description

This role configures [Logos Execution Zone](https://github.com/logos-blockchain/logos-execution-zone) set of containers.

# Configuration

Basic configuration should include sequencer and indexer configs as well as initial peers:
```yaml
lez_cont_tag: 'v0.2.0'
lez_blockchain_cont_tag: '0.2.0'
lez_sequencer_config: '{{ lookup("file", "files/sequencer_config.json") }}'
lez_indexer_config: '{{ lookup("file", "files/indexer_config.json") }}'
lez_blockchain_initial_peers:
  - '/ip4/65.108.203.235/udp/3000/quic-v1/p2p/12D3KooExamplePeer1'
  - '/ip4/65.108.203.235/udp/3001/quic-v1/p2p/12D3KooExamplePeer2'
  - '/ip4/65.108.203.235/udp/3002/quic-v1/p2p/12D3KooExamplePeer3'
  - '/ip4/65.108.203.235/udp/3003/quic-v1/p2p/12D3KooExamplePeer4'
```
This generates files in `conf` directory:
```bash
 > find /docker/logos-exec-zone/conf -type f 
/docker/logos-exec-zone/conf/indexer/config.json
/docker/logos-exec-zone/conf/sequencer/config.json
/docker/logos-exec-zone/conf/blockchain/keystore.yaml
/docker/logos-exec-zone/conf/blockchain/config.yaml
```
Blockchain config is generated by `blockchain-init` container before the `blockchain` container starts.
